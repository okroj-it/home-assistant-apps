# Home Assistant apps by okroj-it

[![Add the repository to Home Assistant][badge]][add]

| App | |
|---|---|
| [doorkey](doorkey) | Phone keypad for the front door from an NFC tap, and fingerprint-confirmed actions. |

## Install

Click the button above, or in Home Assistant go to **Settings → Apps → App
store → ⋮ → Repositories** and add:

```text
https://github.com/okroj-it/home-assistant-apps
```

Images are built and published from each app's own repository, e.g.
[okroj-it/doorkey](https://github.com/okroj-it/doorkey).
