# doorkey

Phone keypad for the front door from an NFC tap, and fingerprint-confirmed
Home Assistant actions.

![Supports aarch64][aarch64] ![Supports amd64][amd64]

Admin in the Home Assistant sidebar, SQLite in the app's storage, Home
Assistant and MQTT access through the Supervisor: no tokens to copy.
